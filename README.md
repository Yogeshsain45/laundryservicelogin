# Laundry Service Login Page

## Project Description

This project is a simple Laundry Service Login Page created using HTML and CSS.
It contains a laundry image on the left side and a login form on the right side.

## About
I created a simple login page using HTML and CSS.
The main purpose of this task was to practice Flexbox.

## Features

- Simple and clean login page
- Email and Password input fields
- Forgot Password option
- Login button
- Register Now option
- Laundry image
- Flexbox for proper alignment

## Technologies Used
- HTML
- CSS
- Flexbox

## Files

- `index.html` - Contains the structure of the webpage.
- `index.css` - Contains the styling of the webpage.
- `laundryservice.webp` - contain the image 

## Features
- Email input
- Password input
- Login button
- Forgot Password link
- Sign Up link

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a browser.

## What I Learned
I learned how to use Flexbox to center elements horizontally
and vertically. I also learned how 100vh works and how
box-sizing affects the size of elements.
